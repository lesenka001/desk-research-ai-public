# План SPEC 001

1. Зафиксировать конфигурацию Open WebUI: базовый URL, API key и обязательный
   ID модели; убрать значения OpenRouter из runtime и развёртывания.
2. Перевести запрос и безопасную диагностику worker и `quality_check.py` на
   Open WebUI. Проверить поведение структурированного ответа и ошибок.
3. Обновить документацию запуска и тесты. Отдельный агент пишет тесты,
   отдельный агент запускает полный набор тестов и проверяет diff.
4. После проверки оформить один коммит для задачи T1. Живой пробный запрос
   выполнить, когда ключ будет настроен в среде; рабочее развёртывание —
   только по отдельному указанию владельца.
