# SPEC-F2-HOTFIX-2: отображение сохранённых процентных находок

## Зачем это читателю

Контрольная обработка успешно сохранила 13 находок, но Mini App показывает ноль.
Первый hotfix устранил исключение `psycopg` в параметризованных запросах, однако
в запросах без параметров экранированная последовательность `%%` доходит до
PostgreSQL без преобразования. В результате фильтр ищет два знака процента и не
находит обычные значения вида `38%`.

Hotfix должен показать уже сохранённые находки в Mini App и Telegram, не запуская
повторную обработку материалов.

## Что меняется и в каких файлах

- `bot/main.py` — регулярное выражение строится без литерального `%` в строке
  запроса: знак процента добавляется средствами PostgreSQL через `chr(37)`.
  Такой запрос одинаково работает с параметрами и без них.
- `tests/test_views.py` — регрессионная проверка охватывает оба режима подготовки
  запроса `psycopg`: с параметрами и без параметров.

Правила отбора, сохранённые находки и настройки повторной обработки не меняются.

## Как проверим

### Автоматически

- запрос без параметров содержит выражение с `chr(37)` и не ищет `%%`;
- параметризованный запрос подготавливается без ошибки плейсхолдера;
- оба варианта требуют один знак `%` в значении находки;
- проходят все тесты репозитория и проверка JavaScript Mini App.

### По базе и экрану после redeploy

- 13 находок материала `3` остаются в базе;
- Mini App показывает их вместо нулевого результата;
- в Runtime Logs `bot` нет ошибок подготовки SQL;
- подходящие ещё не отправленные находки могут попасть в Telegram;
- `REPROCESS_OLD=0`, `REPROCESS_MATERIAL_IDS` пустой.

## Задачи по порядку

### F2-H2. Сделать процентный фильтр единым для всех запросов

1. Заменить литеральное экранирование процента на построение регулярного
   выражения через `chr(37)`.
2. Расширить регрессионный тест режимами с параметрами и без параметров.
3. Запустить новый тест, все тесты и проверку JavaScript.
4. Сделать один коммит с номером `F2-H2` в сообщении.

**Тест:** оба способа подготовки SQL проходят без исключений и формируют фильтр
одного знака процента, не превращая его в поиск `%%`.
